UI-елементи: опис та приклади

Лабораторна робота з QC Fundamentals. На сторінці розміщено 10 UI-елементів, для кожного наведено призначення та приклад.

1. Radiobutton

Radiobutton дозволяє вибрати лише один варіант із групи. Використовується для взаємовиключних виборів, наприклад стать або спосіб оплати. Кнопки однієї групи мають однакове ім’я, тому при виборі нового варіанта попередній знімається.

4. Tabs

Tabs розділяють вміст на окремі розділи, які відкриваються кліком по заголовку. Використовуються для навігації між пов’язаними розділами, наприклад профіль і налаштування. Зменшують перевантаження сторінки.

5. Button

Button виконує дію після натискання: зберегти, надіслати, видалити. Може мати різний стиль залежно від важливості дії. Недоступна кнопка не реагує на натискання.

6. Text label

Text label містить пояснювальний текст: назву поля, інструкцію або повідомлення про стан. Допомагає зрозуміти призначення інших елементів.

7. Link

Link переводить користувача на іншу сторінку або ресурс. Зазвичай підкреслене та виділене кольором. Може відкриватися в тій самій або в новій вкладці.

8. Tooltip

Tooltip показує додаткову інформацію при наведенні курсора на елемент. Використовується для пояснень без перевантаження інтерфейсу.
